# ICC System Design

Meu estudo público de engenharia de sistemas ICC (*Integrated Control Center*) ferroviários: supervisão de trens (ATS), SCADA, segurança funcional, modelagem e a infraestrutura que sustenta um centro de controle.

Sou técnico de sinalização ferroviária e estudo para levar essa experiência de campo para o projeto de sistemas.

## Como funciona

A formação é conduzida com o [AI Tutor](https://github.com/14lucas-mendes/ai-tutor-skill), uma skill open source que criei. Ela segue regras rígidas: tema novo começa do zero, e só conta como progresso o que eu faço sozinho, nunca o texto gerado pela IA.

- [Currículo](curriculum.md): 43 temas em 10 fases.
- [Registro de sessões](session-log.md): o que foi estudado e quando.
- [Lições](lessons/): a teoria de cada tema.
- [Projeto ICC Linha Aurora](projects/icc-linha-aurora/): um ICC de uma linha fictícia, do requisito ao dossiê final.
- [`.ai-tutor/state.json`](.ai-tutor/state.json): progresso medido e evidências.

## Regras deste repositório

- Todos os dados de projeto são fictícios.
- Nenhum documento interno de empresa entra aqui.
- Normas pagas são estudadas por fontes públicas, sem reproduzir o texto delas.
- O progresso mostrado é o medido. Se um tema está em 0, é porque ainda não há evidência.
